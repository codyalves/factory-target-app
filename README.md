# factory-target-app

The app built and maintained by [software-factory](https://github.com/codyalves/software-factory):
a platform that turns information a company supplies into a website, and
(soon) a chatbot that answers from that information alone.

The demo company, Juniper Ridge Coffee Roasters, is fictional.

Changes arrive as pull requests from the factory, each traced to the issue's
acceptance criteria and the tests that cover them. See the factory's
README for how that works.

```bash
pnpm install
pnpm dev
```
